# 書き方

ソースと修正のまとめの書き方を書く．作業の手順は [workflow.md](workflow.md) にある．本ごとに決めること（番号の付け方，文献の表示，記号，担当の表など）は本のリポジトリの `docs/book.md` にあり，この文書と食い違うときはそちらに従う．

ここでいう「原書」は TeX 化する元の本，「忠実版」は原書どおりの版（`original.pdf`），「修正版」は誤りを直し，証明の簡略化や補完を入れた版（`revised.pdf`）である．訳の本では，忠実版は原書に忠実な訳になる．

## 忠実版と修正版

2 つの版は別のソースである．

- 忠実版は `tex/original/<名前>.tex`．原書どおりの書き起こし（原書の誤りもそのまま）である．
- 修正版は `tex/revised/<名前>.tex`．忠実版を写したものに修正を入れる．普通の TeX として直接編集する．
- 忠実版を直したときは，`make sync` で同じ直しを修正版に取り込む（workflow.md の「忠実版を直す」）．

## 番号とラベル

- 定理・定義・系・注意・例などの番号の付け方（節ごとの共通番号か，章ごとか）は原書と同じにする．
- ラベルは **`接頭辞:原書の番号`** で付ける．修正版で番号が変わっても，ラベルは原書の番号のままにする（項目を見分ける名前として使う）．修正版で足した項目のラベルは「番号」の節のとおり．

  | 対象 | 例 |
  |---|---|
  | 定理・定義など | `\label{thm:1.1.1}`（種類によらず `thm:`） |
  | 数式 | `\label{eq:1.12}` |
  | 図 | `\label{fig:1.1}` |
  | 章・節・小節 | `\label{ch:1}`, `\label{sec:1.1}`, `\label{sec:1.1.2}` |
  | 付録 | `\label{app:A}`（付録の中の定理は `thm:A.1`，式は `eq:A.1`） |

- 複数行で番号が 1 つの式は `equation` の中に `aligned` や `gathered` を置く．
- 前付け・後付け（まえがき，文献など）は `\chapter*` を使い，`\addcontentsline{toc}{chapter}{…}` で目次に載せる．

## 参照

- 参照には `\ref` ではなく `\bref{thm:1.1.2}`，数式は `\beqref{eq:1.1}`（括弧付き）を使う．「定理\bref{thm:1.1.2}」「\bref{sec:1.2}節」のように，種類の語は本文に書く．
- 参照先の章がまだ TeX 化されていなければ，ラベル名の番号（`1.1.2`）がそのまま表示される．その章を TeX 化すれば自動的にリンクになる．
- 文献は `\bcite{…}` で引く．
- 修正版で補う文では，対称性や定義の当てはめのような初等的な性質を番号で引かず，「対称性から」のように言葉で書く．

## 修正版

### 目印

- 原書を直した箇所には，その先頭に目印 `\fixat{ID}` を置き，直した文を書く．`\fixat` は何も出力しない．数式中でも使える．
- ID は `章-連番`（`4-01`, `4-02`, …）．一度振った ID は振り直さない．`章` の部分は英大文字と数字だけにする（`3A-01` はよいが `3a-01` は `make check` が ID と認めない）．
- 1 つの修正が複数箇所にわたるときは，それぞれの箇所に同じ ID の `\fixat` を置く．
- 見出しを直したときは，`\fixat` を見出しの直前か直後に置く（見出しの引数（`\section{…}`，`\begin{theorem}[…]`）の中に置くと，しおりに ID が紛れ込むことがある）．
- 注記は `\fixat{ID}（注：……）` と書く．

### 印

種類に「補完」「注記」「簡略化」「書き換え」のどれかを含む修正は，長さによらず，修正した範囲の全体を印で囲む．

- 種類に「補完」か「注記」を含む修正は［補完］…［補完ここまで］（`\supplied{…}`），「簡略化」か「書き換え」を含む修正は［書き換え］…［書き換えここまで］（`\rewritten{…}`）．
- 印は `\fixat{ID}` の直後に置く（`\fixat{1-02}\supplied{…}`）．修正が 1 つの証明環境だけのときは環境の中に置く（`\fixat{1-02}\begin{proof}\supplied{…}\end{proof}`）．

### 番号

- 修正版の番号は，修正版の並びのとおりに振る．定理類や式を消したり，移したり，足したりすると，後の番号は原書とずれる．
- 原文の中のラベル（`\label{eq:1.5}` など）は，修正版でも同じ式や定理に残す（番号が変わっても，参照が同じ式や定理を指すように）．
- 修正版の番号が原書と違う定理類には，見出しの余白に「原 補題 4.34」と原書の番号が自動で出る（`\label{thm:4.34}` のラベル名の番号と実際の番号を比べる）．種類を変えた（補題を系にしたなど）ときは，`\label` の前に原書の種類を `\origname{補題}` と書く（`\begin{corollary}\origname{補題}\label{thm:4.34}`）．式には出ない．
- 原書にない式や定理類は普通の環境で書き，ラベルは **`rev:修正 ID`** にする（`\label{rev:1-09}`．同じ修正で複数あるときは `rev:1-09a`，`rev:1-09b`，…）．番号を付けるのは，ほかの箇所から参照するものだけにする．
- 本の `docs/book.md` で番号を原書と同じに保つと決めた本では，消した式や定理の後に `\fixskip{equation}{2}` のように消した数だけ番号を進め，原書にない式や定理類には直前の番号にアルファベットを付けた番号を振る．式は `\begin{equation*}\addtag\label{rev:1.20a}` で (1.20a)，(1.20b)，… と自動で振られ，定理類は本の sty で `\newaddtheorem{addlemma}{補題}`（定理類が `theorem` 以外のカウンタを共有する本は `\newaddtheorem[definition]{addlemma}{補題}`）のように作った環境で「補題 1.2.3a」となる．このときのラベルは `rev:` と付けたときの番号．定理類を移すことはしない．
- 原書の番号を残すときは `\begin{equation*}\tag{1.22}\label{eq:1.22}` と書く．
- 原書の主張の証明を補うときは，`proof` 環境か原書の証明の中に書く．証明の途中の補助的な主張は `\textbf{主張．}` で番号なしでよい．

## 修正のまとめ

`corrections/<章のファイル名>.md` に書く．書式は `common/example/corrections/ch01.md` にならう．

- 修正ごとに，一覧の表に 1 行足し，`### ID 見出し` の項目を書く．
- 一覧の種類と，項目に書くこと:

  | 種類 | 項目に書くこと |
  |---|---|
  | 誤植，誤字，論理など | 原文と修正 |
  | 記述（簡略化）（主張・定義・仮定を同値で簡潔な形に書き換えたもの） | 「同値である理由」（使った本書の仮定を含む） |
  | 主張（補完）（主張を強め，強めた分を証明したもの） | 原書の主張と強めた主張 |
  | 注記 | 「**直さなかった理由**」，分かれば「**正しい形の候補**」 |
  | 証明（簡略化），証明（補完） | 使った事実を「前提にした事実」に．「原書の証明」「修正版の証明（補ったこと）」「良くなった点」「補えなかったこと」は必要に応じて |

- md では，原書の定理や式を原書の番号で呼ぶ（「原書の箇所」の欄も）．修正版で足したものは修正 ID で呼び（「1-09 の命題」），修正版の番号で呼ぶときは「修正版の命題 1.1.4」と断る．
- 後の修正で置き換えた範囲に入って修正版から消えた ID は，項目に「`- **修正版には出ない**: X-YY で置き換えた範囲にある．`」と書く．
- 「修正しなかった点・メモ」には，誤りではない記述についての注意，原書が省略を明示していて補えなかった（またはまだ補っていない）証明，修正・注記の背景説明を書く．原書の誤りに触れるときは，対応する ID を書く．

### 取り下げ

入れた修正を修正版から外すときは，修正版を前の文面に戻して `\fixat` を消し，md の項目と一覧表の行は残して，項目に「**取り下げ**: （理由）．外した文面はコミット `<hash>` にある．」の欄を書く．ID の一部だけを外すときは「**一部取り下げ**」と書く．

## その他

- 用語の太字（原書の太字）は `\term{...}`．
- 原書のページ境界には，本文か最初の `\item` の先頭に `\origpage{2}` を置く（余白に「原 p.2」と出る）．修正版で書き換えた範囲の中にページ境界があるときは，修正版の対応する位置にも置く．
- 記号は本の記号のマクロ（`tex/notation.sty` など）を使う．
